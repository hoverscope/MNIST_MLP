# 🧠 Custom Multi-Layer Perceptron on MNIST Dataset

This project is a custom implementation of a Multi-Layer Perceptron (MLP) in Python, achieving a high accuracy of **98%** on the MNIST dataset. 📈 

The MNIST dataset has been reduced to 64 pixels instead of the original 784 pixels for faster training and evaluation. 

## NOTE: The model is capable of achieving even higher accuracy with further tuning and improvements.

## 🚀 Features

- Custom Python implementation of MLP for digit classification 🖥️
- Optimized for performance with a reduced feature set (64 pixels) ⚡
- High test accuracy: **98%** ✅
- Compatible with `Dataset1.csv` (training data) and `Dataset2.csv` (test data) 📂

## 📊 Dataset Details

- **Training Dataset**: `Dataset1.csv`
- **Test Dataset**: `Dataset2.csv`
- Both datasets are pre-processed for reduced pixel input (64 features).

## 🛠️ Installation

1. Clone the repository or download the project files.
2. Install required dependencies using `pip install -r requirements.txt`.
3. Ensure `Dataset1.csv` and `Dataset2.csv` are placed in the root directory.
4. Run the training script: `python train_model.py`.
